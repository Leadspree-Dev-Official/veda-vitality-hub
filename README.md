## 📋 Project Overview

Veda Vitality Hub is a modern web application built with React and TypeScript, featuring a beautiful UI and responsive design.

## 🛠️ Tech Stack

- **Frontend:** React 19
- **Routing:** TanStack Router
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4
- **UI Components:** shadcn/ui (Radix UI)
- **Language:** TypeScript
- **State Management:** TanStack Query

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Bun (recommended) or npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Leadspree-Dev-Official/veda-vitality-hub.git
cd veda-vitality-hub

# Install dependencies (using bun)
bun install

# Or using npm
npm install
```

### Development

```bash
# Start development server
bun run dev

# Or using npm
npm run dev
```

### Build

```bash
# Build for production
bun run build

# Preview production build
bun run preview
```
